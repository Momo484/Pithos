## Overview 
This file contains the typedef for a bitboard and some useful constants used across the engine. Specifically 
- typedef uint64_t Bitboard -> allows use to call uint64_t a Bitboard across the engine
- EMPTY_BOARD -> as it sounds. 
- FULL_BOARD -> as it sounds.
- RANK_K -> masks off the kth rank.
- FILE_K -> masks off the kth file.
